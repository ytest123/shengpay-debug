安装步骤

1
下载并解压

下载上方「技能包 zip」，解压后会看到 shengpay-codegen/ 文件夹，含 SKILL.md、scripts/、references/。

2
放入 WorkBuddy 技能目录

Windows（PowerShell）

$skillPath = "$env:USERPROFILE\.workbuddy\skills"; if (!(Test-Path $skillPath)) { New-Item -ItemType Directory -Path $skillPath }; Copy-Item -Recurse -Force .\shengpay-codegen $skillPath\

macOS / Linux

mkdir -p ~/.workbuddy/skills && cp -r shengpay-codegen ~/.workbuddy/skills/
3
重启 WorkBuddy

WorkBuddy 在启动时扫描技能目录，必须重启才能识别新增的 shengpay-codegen。关闭当前窗口重新打开即可。

4
验证安装

打开 WorkBuddy → 左侧「技能」面板 → 搜索 shengpay-codegen，能看到即安装成功。

5
试着说一句触发语

在对话框里粘贴以下任意一句：

生成 pay.unifiedorderOffline 的 Java 示例
生成 refund.orderRefund 的 PHP 示例
盛付通下单 Node.js 代码

技能能力

维度支持项
接口pay.unifiedorderOffline（下单）/ pay.queryOrder（查询）/ refund.orderRefund（退款）/ refund.queryRefundOrder（退款查询）
语言Node.js / Java / C# / PHP
签名算法SHA1WithRSA + Base64
私钥长度RSA 1024（与盛付通商户平台一致）
私钥格式PKCS#8 · Base64（不含头尾 -----BEGIN/END-----）
加签规则除 sign 外按 key 升序拼接，空值不参与，末尾不带 &

常见问题

左侧栏没显示技能 —— 必须重启 WorkBuddy；检查 ~/.workbuddy/skills/shengpay-codegen/SKILL.md 第一行是否为 name: shengpay-codegen。
输入触发语没反应 —— SKILL.md 的 description 包含完整触发词；可改用「盛付通」「shengpay」「SHA1WithRSA」等关键词尝试。
生成器运行报错 —— 需要 Node.js ≥ 18；在终端跑 node scripts/gen.js pay java 看具体错误。
Java 示例编译失败 —— 需要 JDK ≥ 8；编译时务必加 -encoding UTF-8，否则中文参数会乱码。
需要长期维护 + 一键升级？ —— 走方式二（自建市场），把本目录推送 git 仓库后，同事一行命令就能安装并自动跟随你后续的更新。
