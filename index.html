盛付通多语言示例代码生成 · 已从当前页面沉淀为 WorkBuddy 技能

把下载下来的 zip 解压到 ~/.workbuddy/skills/shengpay-codegen/，重启 WorkBuddy 即可在任意对话中用以下触发语生成可运行代码：

生成 pay.unifiedorderOffline 的 Java 示例
下载技能包 zip 下载市场仓库整包 查看完整说明 ↗
1
下载并解压

点击上方「下载技能包 zip」，解压后会看到 shengpay-codegen/ 文件夹（含 SKILL.md、scripts/、references/）。

2
放入技能目录

Windows（PowerShell）：

$env:USERPROFILE\.workbuddy\skills\shengpay-codegen  ← 目标路径
Copy-Item -Recurse -Force .\shengpay-codegen $env:USERPROFILE\.workbuddy\skills\

macOS / Linux：

mkdir -p ~/.workbuddy/skills
cp -r shengpay-codegen ~/.workbuddy/skills/
3
重启 WorkBuddy

WorkBuddy 启动时才扫描技能目录，必须重启才能识别新增的 shengpay-codegen。

4
验证安装

打开 WorkBuddy → 左侧「技能」面板 → 搜索 shengpay-codegen，能看到即安装成功。然后在对话框粘贴上面的触发语，WorkBuddy 会自动调用技能生成代码。
